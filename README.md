# GF2 Exilium Translation Launcher

Лаунчер устанавливает русский перевод для **Girls’ Frontline 2: Exilium** и запускает игру.

## Скачать и запустить

Эта версия лаунчера предназначена для **Windows**. Все библиотеки уже входят в EXE.

1. На странице [релизов GitHub](https://github.com/Falcon411/GF2-Exilium-Translation-Launcher/releases) откройте **Assets** и скачайте `Gf2ExiliumTranslationLauncher.exe`.
2. Закройте игру и откройте скачанный EXE. Лаунчер попробует найти игру автоматически. Если поиск не сработал, выберите `GF2_Exilium.exe` через **«Настройки» → «Обзор»**.
3. Нажмите **«Запустить»**. Лаунчер скачает перевод и откроет игру.
4. В настройках игры выберите **English** в качестве языка текста. Русский перевод заменяет английский текст.

## Обновления

- **Перевод** проверяется и обновляется автоматически при запуске игры через лаунчер.
- **Игру** обновляйте через официальный лаунчер.
- **Лаунчер перевода** обновляется заменой EXE. Оставьте `config.json` рядом с новым EXE, чтобы сохранить настройки.

## Как вернуть оригинальный текст

Закройте игру и выберите **«Настройки» → «Сбросить весь перевод»**. Подтвердите сброс и откройте игру через официальный лаунчер. Кнопка **«Запустить»** в лаунчере перевода установит перевод снова.

## Если что-то не работает

- **Лаунчер не находит игру.** В настройках нажмите **«Сбросить путь и найти игру заново»** или выберите `GF2_Exilium.exe` через **«Обзор»**.
- **Текст в игре на английском.** Проверьте, что запустили игру через лаунчер перевода и выбрали **English** как язык текста. Строки, которые ещё не переведены, останутся на английском.
- **После обновления игра сообщает об ошибке файлов.** Закройте игру, запустите проверку файлов через официальный лаунчер и попробуйте снова.
- **Перевод не скачивается.** Проверьте, открывается ли GitLab, и повторите попытку. Журналы ошибок находятся в папке `logs` рядом с EXE.
