# GF2 Exilium Translation Launcher

Неофициальный лаунчер для **Girls’ Frontline 2: Exilium**. Он устанавливает русский перевод, проверяет его обновления перед запуском игры и позволяет вернуть оригинальные файлы.

## Что понадобится

- Компьютер с **Windows x64** и установленная игра Girls’ Frontline 2: Exilium.
- Файл `Gf2ExiliumTranslationLauncher.exe`. На GitHub готовые сборки ищите в разделе [Releases (релизы)](https://github.com/Falcon411/GF2-Exilium-Translation-Launcher/releases). Если у вас уже есть локальная сборка проекта, она лежит в папке `artifacts/launcher`.
- Интернет для первой установки перевода и проверки обновлений.

Готовому EXE не нужны отдельная установка .NET или дополнительные библиотеки.

## Как запустить игру с русским переводом

1. Если игра открыта, закройте её. Запустите `Gf2ExiliumTranslationLauncher.exe`.
2. Дождитесь автоматического поиска игры. Если лаунчер её не нашёл, откройте **«Настройки» → «Обзор»** и выберите файл **`GF2_Exilium.exe`**. Например, он может лежать по пути `D:\GF2Exilium\GF2 Game\GF2_Exilium.exe`.
3. Нажмите **«Запустить»**. Лаунчер проверит перевод, при необходимости скачает и установит его, затем откроет игру.
4. В настройках игры выберите **английский язык текста (English)**. Русский перевод занимает место английского текста, поэтому отдельный пункт «Русский» в меню игры не появится.

## Как обновлять

- **Перевод.** Запускайте игру через наш лаунчер. Он сравнивает два источника на GitLab и устанавливает более свежий подходящий вариант. При временной недоступности GitLab лаунчер может использовать ранее установленный перевод, если проверка локального файла проходит.
- **Игра.** Обновляйте её через официальный лаунчер. После обновления снова откройте наш лаунчер и нажмите **«Запустить»**, чтобы он проверил перевод.
- **Наш лаунчер.** Закройте его и замените EXE новым файлом. Оставьте рядом `config.json`: в нём хранятся путь к игре и данные об установленном переводе.

## Как вернуть оригинальный текст

1. Закройте игру.
2. В нашем лаунчере откройте **«Настройки» → «Сбросить весь перевод»** и подтвердите действие.
3. Чтобы играть с оригинальным текстом, запустите игру через официальный лаунчер. Кнопка **«Запустить»** в нашем лаунчере снова установит перевод.

## Если что-то не работает

- **Лаунчер не видит игру.** В настройках нажмите **«Сбросить путь и найти игру заново»** или укажите `GF2_Exilium.exe` через **«Обзор»**. Выбирайте файл игры внутри её папки установки.
- **Игра запустилась, но текст на английском.** Проверьте, что вы запустили игру кнопкой **«Запустить»** в нашем лаунчере и выбрали **English** именно в настройке языка текста игры. Некоторые строки могут оставаться на английском, если их ещё не перевели.
- **После патча появилась ошибка проверки файлов.** Закройте игру и запустите проверку файлов через официальный лаунчер. Затем повторите запуск через наш.
- **Перевод не скачивается.** Проверьте, открывается ли GitLab, и попробуйте снова. Если ошибка повторяется, последние журналы лежат в папке `logs` рядом с EXE.

## Источники перевода

Лаунчер использует [пакет переводов в JSON](https://gitlab.com/girls-frontline2-ru-team/girls-frontline-team-translate/-/releases/translations-latest) и [готовую таблицу локализации](https://gitlab.com/gf2-ru-team/girls-frontline-2-exilium-russian-localization). Скачивать их вручную не нужно.

## Сборка из исходников

Для сборки нужны **.NET 10 SDK** и доступ к **NuGet**. Откройте PowerShell в корне проекта и выполните:

```powershell
dotnet publish src/Gf2ExiliumTranslationLauncher/Gf2ExiliumTranslationLauncher.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -o artifacts/launcher
```

Готовый файл появится в `artifacts/launcher/Gf2ExiliumTranslationLauncher.exe`.
